# Các thao tác cần thực hiện trên iPhone — khi thiếu quyền tạo kho

1. Mở https://github.com/new bằng Safari/Brave và đăng nhập GitHub.
2. Repository name: `duckduckgo-vietnamese`.
3. Visibility: **Public**. Đừng bật **Add a README file** để kho trống.
4. Nhấn **Create repository**.
5. Trở lại cuộc trò chuyện ChatGPT, gửi URL kho vừa tạo, ví dụ `https://github.com/<username>/duckduckgo-vietnamese`.

Sau đó trợ lý có thể dùng kết nối GitHub để thêm tệp của dự án. Nếu có thông báo **grant access to repository**, hãy chọn đúng repository mới. Không cần cấp quyền cho các kho NEXUS hoặc Vietsub.

**Lưu ý:** sau khi CI thử build, tệp IPA chưa ký vẫn không thể cài trên iPhone. Việc ký ứng dụng bằng Apple ID/chứng chỉ là một bước riêng. Không chia sẻ mật khẩu Apple ID hay mã 2FA cho trợ lý.
